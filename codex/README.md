# Codex 原生宠物归档

Codex 原生版已暂停维护。这里保存 v1.0.0 时期的宠物清单、动画、安装脚本和研究记录。[v1.0.0 历史发布](https://github.com/li1-init/Kirino-Kousaka-Desktop-Pet/releases/tag/v1.0.0)提供原生安装 ZIP。日常开发请进入[独立 Windows 项目](../windows/README.md)。

如需恢复历史原生版本，可以在仓库根目录运行 `./codex/scripts/Restore-Pet.ps1 -Revision v1.0.0`。脚本安装到本机 Codex 宠物目录，`-Destination` 可指定临时目录。历史文档中的命令和路径以其原版本为准。
