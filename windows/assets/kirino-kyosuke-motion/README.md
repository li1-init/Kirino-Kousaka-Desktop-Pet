# 桐乃与京介 · Windows 桌宠动作素材

这里收录 24 个动作。京介采用已确认的西装校服造型。桐乃的 Codex 会话动作有木凳和坐垫两套，每套包含打字、看屏幕思考、回眸脸红三个动作。会话预览以打字为常态，每 30 秒看向屏幕思考，每 2 分钟回眸脸红、嘟嘴，再转回电脑。

在浏览器打开 [动作预览](action-motion/preview.html) 即可逐个查看动作。每个动作默认 60 FPS、3.10 秒，整体锚点固定，预览内可独立调速。此素材包通过独立网页预览，Windows 应用需要另行接入。

- [动作目录](action-catalog.json) 记录参考平台、集数、时间点、演出设计和文件位置。
- [成品动画与调速图集](action-motion/standard/) 包含透明 WebP 和逐帧调速用的 WebP 图集。当前版本以动作目录引用为准，早期版本也随包保留。
- [动作草稿](action-previews/)、[关键帧图](action-sources/) 和 [帧率对比](fps-comparison/compare.html) 记录制作过程。
- [生成脚本](action-motion/build-motion.py) 从素材重新渲染成品和调速图集，使用 Python、Pillow、NumPy 和 OpenCV。

动画与图集为本次桌宠设计生成的二次创作素材。原作情节和上游项目姿势的参考出处见动作目录。
